🔌 Connect Google Drive

Follow these steps once to load your real family photos automatically.

1
Create a Google Cloud Project Go to console.cloud.google.com → New Project → Enable the Google Drive API.
2
Create an API Key APIs & Services → Credentials → Create API Key. Restrict it to Drive API only for safety.
3
Organise Google Drive folders Create a main folder with sub-folders: Wife, Daughter, Mother, Father, Me. Upload photos inside them.
4
Share the main folder publicly Right-click folder → Share → Anyone with the link → Viewer. This lets the API read it.
5
Paste your API Key & Folder ID below The Folder ID is the long string in the Drive URL after /folders/.
